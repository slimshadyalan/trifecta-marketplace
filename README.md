# Trifecta Macro Filter (Claude plugin)

AI macro research assistant for Claude. Research and market context only — not financial advice, trade signals or recommendations.

## Install (Claude Pro, Max, Team or Enterprise)
1. In Claude, open **Customize** > **Plugins**.
2. Click **Add** > **Add marketplace** > **Add from a repository**.
3. Enter: `YOUR-GITHUB-USERNAME/trifecta-marketplace`
4. Open **Discover**, find **Trifecta Macro Filter** and click **Add**.
5. Turn on web search, then ask e.g. "What are the latest rate probabilities?"
